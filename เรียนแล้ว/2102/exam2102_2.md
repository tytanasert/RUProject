## 📌 หลักการสำคัญที่ต้องจำ

### Virtual Function (Polymorphism)
```
ถ้าใช้ pointer/reference ของ base class ชี้ไปที่ derived object:
- มี virtual    → เรียก method ของ derived class (runtime binding)
- ไม่มี virtual → เรียก method ของ base class (compile-time binding)
```

### Shallow vs Deep Copy
```
Shallow: คัดลอก pointer → 2 object ชี้ memory เดียวกัน
Deep:    คัดลอกค่า → แต่ละ object มี memory ของตัวเอง
```

## 📘 Final 54

### โจทย์แนว: Virtual Function + Pointer

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    virtual void sound() { cout << "..." << endl; }
    void type() { cout << "Animal" << endl; }
};

class Dog : public Animal {
public:
    void sound() { cout << "Woof!" << endl; }
    void type() { cout << "Dog" << endl; }
};

class Cat : public Animal {
public:
    void sound() { cout << "Meow!" << endl; }
    void type() { cout << "Cat" << endl; }
};

int main() {
    Animal* a;
    Dog d;
    Cat c;

    a = &d;
    a->sound();   // virtual → เรียก Dog::sound()
    a->type();    // ไม่ virtual → เรียก Animal::type()

    a = &c;
    a->sound();   // virtual → เรียก Cat::sound()
    a->type();    // ไม่ virtual → เรียก Animal::type()

    d.sound();    // เรียกตรง → Dog::sound()
    d.type();     // เรียกตรง → Dog::type()

    return 0;
}
```

### เฉลย

```
Woof!       ← a->sound() เมื่อ a ชี้ Dog (virtual → runtime binding → Dog::sound)
Animal      ← a->type()  ไม่มี virtual → compile-time binding → Animal::type
Meow!       ← a->sound() เมื่อ a ชี้ Cat (virtual → Cat::sound)
Animal      ← a->type()  ไม่มี virtual → Animal::type
Woof!       ← d.sound()  เรียกตรงจาก Dog object
Dog         ← d.type()   เรียกตรงจาก Dog object
```

**⚠️ จุดสำคัญ:** `type()` ไม่มี `virtual` → ไม่ว่า pointer ชี้ object อะไร ก็เรียกของ base เสมอ

## 📘 Final 58

### โจทย์แนว: Operator Overloading + Copy Constructor

```cpp
#include <iostream>
using namespace std;

class Number {
    int* val;
public:
    Number(int v) {
        val = new int(v);
        cout << "Num(" << v << ")" << endl;
    }
    Number(const Number& n) {
        val = new int(*n.val);
        cout << "Copy(" << *val << ")" << endl;
    }
    Number& operator=(const Number& n) {
        *val = *n.val;
        cout << "Assign(" << *val << ")" << endl;
        return *this;
    }
    ~Number() {
        cout << "~Num(" << *val << ")" << endl;
        delete val;
    }
    void show() { cout << "Val=" << *val << endl; }
    void set(int v) { *val = v; }
};

int main() {
    Number a(10);
    Number b(20);
    Number c = a;    // copy constructor (ไม่ใช่ assignment!)
    b = a;           // assignment operator
    a.set(99);
    a.show();
    b.show();
    c.show();
    return 0;
}
```

### เฉลย

```
Num(10)        ← a สร้าง (val=10)
Num(20)        ← b สร้าง (val=20)
Copy(10)       ← c สร้างจาก copy constructor (deep copy จาก a)
Assign(10)     ← b = a; operator= ถูกเรียก
Val=99         ← a.show() (a ถูก set เป็น 99)
Val=10         ← b.show() (b ยังเป็น 10 เพราะ deep copy)
Val=10         ← c.show() (c ยังเป็น 10 เพราะ deep copy)
~Num(10)       ← c ทำลาย (LIFO)
~Num(10)       ← b ทำลาย
~Num(99)       ← a ทำลาย
```

**⚠️ จุดสำคัญ:** เพราะเป็น **deep copy** → เมื่อเปลี่ยนค่า a เป็น 99, b และ c ไม่ได้เปลี่ยนตาม

## 📘 Final 59

### โจทย์แนว: Shallow Copy Problem

```cpp
#include <iostream>
using namespace std;

class Data {
    int* ptr;
public:
    Data(int v) {
        ptr = new int(v);
        cout << "Data(" << v << ")" << endl;
    }
    // ไม่เขียน copy constructor → ใช้ default (shallow copy!)
    ~Data() {
        cout << "~Data(" << *ptr << ")" << endl;
        delete ptr;
    }
    void set(int v) { *ptr = v; }
    void show() { cout << *ptr << endl; }
};

int main() {
    Data a(10);
    {
        Data b = a;   // Shallow copy! b.ptr ชี้ที่เดียวกับ a.ptr
        b.set(99);    // เปลี่ยนค่าที่ memory → a ก็เปลี่ยนด้วย!
        b.show();     // 99
        a.show();     // 99 (เพราะชี้ที่เดียวกัน!)
    }
    // b ถูกทำลาย → delete ptr → memory ถูกคืน
    // a.show();  // ⚠️ UNDEFINED BEHAVIOR! ptr ถูก delete แล้ว!
    return 0;
}
```

### เฉลย

```
Data(10)      ← a สร้าง
99            ← b.show() (หลัง set(99))
99            ← a.show() (shallow copy → a กับ b ชี้ที่เดียวกัน!)
~Data(99)     ← b ทำลาย (ออกจาก scope)
~Data(???)    ← a ทำลาย → 💥 CRASH (double free!)
```

**⚠️ บทเรียน:** ถ้ามี `new` ใน class → **ต้องเขียน** copy constructor และ operator= เอง (deep copy)

### โจทย์แนว: Polymorphism + Array of Pointers

```cpp
#include <iostream>
using namespace std;

class Shape {
public:
    virtual double area() { return 0; }
    virtual void show() { cout << "Shape" << endl; }
    virtual ~Shape() {}
};

class Rect : public Shape {
    int w, h;
public:
    Rect(int w, int h) : w(w), h(h) {}
    double area() { return w * h; }
    void show() { cout << "Rect: " << area() << endl; }
};

class Circle : public Shape {
    int r;
public:
    Circle(int r) : r(r) {}
    double area() { return 3.14 * r * r; }
    void show() { cout << "Circle: " << area() << endl; }
};

int main() {
    Shape* shapes[3];
    shapes[0] = new Rect(5, 10);
    shapes[1] = new Circle(7);
    shapes[2] = new Rect(3, 4);

    for (int i = 0; i < 3; i++) {
        shapes[i]->show();
    }

    for (int i = 0; i < 3; i++) {
        cout << "Area: " << shapes[i]->area() << endl;
        delete shapes[i];
    }

    return 0;
}
```

### เฉลย

```
Rect: 50          ← shapes[0]->show() → Rect::show() (virtual)
Circle: 153.86    ← shapes[1]->show() → Circle::show() (virtual)
Rect: 12          ← shapes[2]->show() → Rect::show() (virtual)
Area: 50          ← shapes[0]->area() → Rect::area()
Area: 153.86      ← shapes[1]->area() → Circle::area()
Area: 12          ← shapes[2]->area() → Rect::area()
```

## 📘 Final 74

### โจทย์แนว: Inheritance + Override + Scope Resolution

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    void func() { cout << "Base::func()" << endl; }
    virtual void vfunc() { cout << "Base::vfunc()" << endl; }
};

class Derived : public Base {
public:
    void func() { cout << "Derived::func()" << endl; }
    void vfunc() { cout << "Derived::vfunc()" << endl; }
};

int main() {
    Derived d;
    Base* bp = &d;
    Base& br = d;

    d.func();        // เรียกตรง → Derived::func()
    d.vfunc();       // เรียกตรง → Derived::vfunc()

    bp->func();      // ไม่ virtual → Base::func()
    bp->vfunc();     // virtual → Derived::vfunc()

    br.func();       // ไม่ virtual → Base::func()
    br.vfunc();      // virtual → Derived::vfunc()

    d.Base::func();  // scope resolution → Base::func()
    d.Base::vfunc(); // scope resolution → Base::vfunc() (ข้าม virtual)

    return 0;
}
```

### เฉลย

```
Derived::func()     ← d.func() เรียกตรง
Derived::vfunc()    ← d.vfunc() เรียกตรง
Base::func()        ← bp->func() ไม่มี virtual → compile-time → Base
Derived::vfunc()    ← bp->vfunc() มี virtual → runtime → Derived
Base::func()        ← br.func() ไม่มี virtual → Base
Derived::vfunc()    ← br.vfunc() มี virtual → Derived
Base::func()        ← d.Base::func() ใช้ scope resolution → Base
Base::vfunc()       ← d.Base::vfunc() scope resolution ข้าม virtual
```

## 📘 Final 75

### โจทย์แนว: operator= vs Copy Constructor

```cpp
#include <iostream>
using namespace std;

class Item {
    string name;
    int* qty;
public:
    Item(string n, int q) : name(n), qty(new int(q)) {
        cout << "Item(" << name << "," << q << ")" << endl;
    }
    Item(const Item& i) : name(i.name), qty(new int(*i.qty)) {
        cout << "CopyItem(" << name << ")" << endl;
    }
    Item& operator=(const Item& i) {
        name = i.name;
        *qty = *i.qty;
        cout << "AssignItem(" << name << ")" << endl;
        return *this;
    }
    ~Item() {
        cout << "~Item(" << name << "," << *qty << ")" << endl;
        delete qty;
    }
};

int main() {
    Item a("Apple", 5);
    Item b("Banana", 3);
    Item c(a);           // Copy Constructor
    Item d = b;          // Copy Constructor (ไม่ใช่ assignment!)
    a = b;               // Assignment Operator
    return 0;
}
```

### เฉลย

```
Item(Apple,5)         ← a สร้าง
Item(Banana,3)        ← b สร้าง
CopyItem(Apple)       ← c สร้างจาก copy constructor ของ a
CopyItem(Banana)      ← d สร้างจาก copy constructor ของ b
AssignItem(Banana)    ← a = b; assignment operator (a ตอนนี้ชื่อ Banana)

~Item(Banana,3)       ← d ทำลาย (LIFO)
~Item(Apple,5)        ← c ทำลาย
~Item(Banana,3)       ← b ทำลาย
~Item(Banana,3)       ← a ทำลาย (ค่าถูกเปลี่ยนเป็น Banana,3 จาก assignment)
```

**⚠️ จุดหลอก:** `Item d = b;` → เป็น **Copy Constructor** ไม่ใช่ Assignment! เพราะ d ยังไม่เคยถูกสร้าง

## 📘 Final 76

### โจทย์แนว: Pure Virtual Function + Abstract Class

```cpp
#include <iostream>
using namespace std;

class Shape {
public:
    virtual double area() = 0;
    void describe() { cout << "Area = " << area() << endl; }
    virtual ~Shape() {}
};

class Square : public Shape {
    int side;
public:
    Square(int s) : side(s) {}
    double area() { return side * side; }
};

class Circle : public Shape {
    int r;
public:
    Circle(int r) : r(r) {}
    double area() { return 3.14 * r * r; }
};

int main() {
    // Shape s;  // ❌ ERROR! Abstract class
    Square sq(5);
    Circle ci(3);

    sq.describe();    // เรียก describe ของ Shape → แต่ area() เป็น virtual → เรียกของ Square
    ci.describe();

    Shape* p = &sq;
    p->describe();
    cout << p->area() << endl;

    return 0;
}
```

### เฉลย

```
Area = 25           ← sq.describe() → area() = Square::area() = 5*5
Area = 28.26        ← ci.describe() → area() = Circle::area() = 3.14*3*3
Area = 25           ← p->describe() → p ชี้ Square → area() = 25
25                  ← p->area() → virtual → Square::area()
```

**⚠️ จุดสำคัญ:** `describe()` ไม่ใช่ virtual แต่ภายในเรียก `area()` ที่เป็น virtual → ยังคงเกิด polymorphism!

## 📘 Final 77

### โจทย์แนว: Virtual Inheritance + Constructor Chain

```cpp
#include <iostream>
using namespace std;

class Person {
    string name;
public:
    Person() : name("?") { cout << "Person()" << endl; }
    Person(string n) : name(n) { cout << "Person(" << n << ")" << endl; }
    void showName() { cout << name << endl; }
    ~Person() { cout << "~Person()" << endl; }
};

class Student : virtual public Person {
public:
    Student() { cout << "Student()" << endl; }
    Student(string n) : Person(n) { cout << "Student(" << n << ")" << endl; }
    ~Student() { cout << "~Student()" << endl; }
};

class Teacher : virtual public Person {
public:
    Teacher() { cout << "Teacher()" << endl; }
    Teacher(string n) : Person(n) { cout << "Teacher(" << n << ")" << endl; }
    ~Teacher() { cout << "~Teacher()" << endl; }
};

class TA : public Student, public Teacher {
public:
    TA() { cout << "TA()" << endl; }
    TA(string n) : Person(n), Student(n), Teacher(n) {
        cout << "TA(" << n << ")" << endl;
    }
    ~TA() { cout << "~TA()" << endl; }
};

int main() {
    cout << "=== ta1 ===" << endl;
    TA ta1;
    ta1.showName();

    cout << "=== ta2 ===" << endl;
    TA ta2("Somchai");
    ta2.showName();

    cout << "=== end ===" << endl;
    return 0;
}
```

### เฉลย

```
=== ta1 ===
Person()         ← Virtual base Person (default constructor)
Student()        ← Student default (Person ไม่ถูกเรียกซ้ำ เพราะ virtual)
Teacher()        ← Teacher default (Person ไม่ถูกเรียกซ้ำ)
TA()             ← TA default
?                ← ta1.showName() → name = "?" (จาก default constructor)

=== ta2 ===
Person(Somchai)  ← Virtual base Person (TA เรียก Person("Somchai") ตรงๆ)
Student(Somchai) ← Student (Person ไม่ถูกเรียกซ้ำ → Student::Person(n) ถูกข้าม!)
Teacher(Somchai) ← Teacher (Person ไม่ถูกเรียกซ้ำ)
TA(Somchai)      ← TA
Somchai          ← ta2.showName() → name = "Somchai"

=== end ===
~TA()
~Teacher()
~Student()
~Person()
~TA()
~Teacher()
~Student()
~Person()
```

**⚠️ สำคัญมาก:** ใน Virtual Inheritance → `Person(n)` ที่เรียกใน `Student(n)` constructor จะ **ถูกข้ามไป!** เพราะ virtual base ถูกสร้างจาก **most-derived class (TA)** เท่านั้น

### 3. Copy Constructor vs Assignment
```
Type obj = other;   → Copy Constructor (สร้างใหม่)
obj = other;        → Assignment Operator (obj ถูกสร้างมาก่อนแล้ว)
```
