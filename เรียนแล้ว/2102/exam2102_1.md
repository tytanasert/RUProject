## 📌 หลักการสำคัญที่ต้องจำ

### ลำดับการเรียก Constructor
```
1. Virtual Base Class (ถ้ามี) → สร้างก่อนเสมอ
2. Base Class (ตามลำดับการสืบทอด ซ้ายไปขวา)
3. Member Objects (ตามลำดับการประกาศใน class ไม่ใช่ลำดับใน initializer list)
4. Constructor ของ class ตัวเอง
```

### ลำดับการเรียก Destructor
```
ย้อนกลับกับ Constructor ทุกประการ (LIFO)
```

## 📘 Final 54

### โจทย์ (ตัวอย่างแนว): ให้ trace output ของโปรแกรมต่อไปนี้

```cpp
#include <iostream>
using namespace std;

class A {
public:
    A()  { cout << "A created" << endl; }
    ~A() { cout << "A destroyed" << endl; }
};

class B {
public:
    B()  { cout << "B created" << endl; }
    ~B() { cout << "B destroyed" << endl; }
};

class C : public A {
    B b;
public:
    C()  { cout << "C created" << endl; }
    ~C() { cout << "C destroyed" << endl; }
};

int main() {
    C c;
    return 0;
}
```

### เฉลย

**ลำดับการสร้าง:**
1. `A created` — Base class (A) สร้างก่อน
2. `B created` — Member object (b) สร้างถัดมา
3. `C created` — ตัว class C สร้างหลังสุด

**ลำดับการทำลาย (ย้อนกลับ):**
4. `C destroyed`
5. `B destroyed`
6. `A destroyed`

```
Output:
A created
B created
C created
C destroyed
B destroyed
A destroyed
```

## 📘 Final 58

### โจทย์แนว: Composition + Inheritance Constructor/Destructor Order

```cpp
#include <iostream>
using namespace std;

class Date {
public:
    Date()  { cout << "Date()" << endl; }
    Date(int d, int m, int y) { cout << "Date(" << d << "," << m << "," << y << ")" << endl; }
    ~Date() { cout << "~Date()" << endl; }
};

class Address {
public:
    Address() { cout << "Address()" << endl; }
    Address(string c) { cout << "Address(" << c << ")" << endl; }
    ~Address() { cout << "~Address()" << endl; }
};

class Person {
    Date d;
    Address a;
public:
    Person() { cout << "Person()" << endl; }
    Person(int dd, int mm, int yy, string city)
        : d(dd, mm, yy), a(city) {
        cout << "Person(params)" << endl;
    }
    ~Person() { cout << "~Person()" << endl; }
};

int main() {
    cout << "--- p1 ---" << endl;
    Person p1;
    cout << "--- p2 ---" << endl;
    Person p2(15, 3, 2025, "Bangkok");
    cout << "--- end ---" << endl;
    return 0;
}
```

### เฉลย

```
--- p1 ---
Date()                    ← member d สร้าง (default)
Address()                 ← member a สร้าง (default)
Person()                  ← ตัว Person สร้าง

--- p2 ---
Date(15,3,2025)           ← member d สร้าง (parameterized)
Address(Bangkok)          ← member a สร้าง (parameterized)
Person(params)            ← ตัว Person สร้าง

--- end ---
~Person()                 ← p2 ทำลาย (LIFO: p2 ก่อน p1)
~Address()                ← p2.a ทำลาย
~Date()                   ← p2.d ทำลาย
~Person()                 ← p1 ทำลาย
~Address()                ← p1.a ทำลาย
~Date()                   ← p1.d ทำลาย
```

## 📘 Final 59

### โจทย์แนว: Inheritance หลายระดับ

```cpp
#include <iostream>
using namespace std;

class A {
public:
    A() { cout << "A()" << endl; }
    ~A() { cout << "~A()" << endl; }
};

class B : public A {
public:
    B() { cout << "B()" << endl; }
    ~B() { cout << "~B()" << endl; }
};

class C : public B {
    A a;
public:
    C() { cout << "C()" << endl; }
    ~C() { cout << "~C()" << endl; }
};

int main() {
    C c;
    return 0;
}
```

### เฉลย

```
A()    ← Base ของ B (A สร้างก่อน)
B()    ← Base ของ C (B สร้าง)
A()    ← Member a ของ C
C()    ← ตัว C สร้าง

~C()   ← C ทำลาย
~A()   ← member a ทำลาย
~B()   ← base B ทำลาย
~A()   ← base A ทำลาย
```

**หลักการ:** ลำดับคือ Base class (ตาม hierarchy) → Member objects → ตัวเอง

## 📘 Final 60

### โจทย์แนว: Multiple Objects + Scope

```cpp
#include <iostream>
using namespace std;

class Widget {
    string name;
public:
    Widget(string n) : name(n) { cout << "Widget(" << name << ")" << endl; }
    ~Widget() { cout << "~Widget(" << name << ")" << endl; }
};

int main() {
    Widget w1("A");
    Widget w2("B");
    {
        Widget w3("C");
        Widget w4("D");
    }   // w4 และ w3 ถูกทำลายตรงนี้ (ออกจาก scope)
    Widget w5("E");
    return 0;
}
```

### เฉลย

```
Widget(A)       ← w1 สร้าง
Widget(B)       ← w2 สร้าง
Widget(C)       ← w3 สร้าง (เข้า inner scope)
Widget(D)       ← w4 สร้าง
~Widget(D)      ← w4 ทำลาย (ออกจาก inner scope, LIFO)
~Widget(C)      ← w3 ทำลาย
Widget(E)       ← w5 สร้าง
~Widget(E)      ← w5 ทำลาย (จบ main, LIFO)
~Widget(B)      ← w2 ทำลาย
~Widget(A)      ← w1 ทำลาย
```

## 📘 Final 74

### โจทย์แนว: Virtual Inheritance Constructor Order

```cpp
#include <iostream>
using namespace std;

class Person {
public:
    Person() { cout << "Person()" << endl; }
    ~Person() { cout << "~Person()" << endl; }
};

class Student : virtual public Person {
public:
    Student() { cout << "Student()" << endl; }
    ~Student() { cout << "~Student()" << endl; }
};

class Teacher : virtual public Person {
public:
    Teacher() { cout << "Teacher()" << endl; }
    ~Teacher() { cout << "~Teacher()" << endl; }
};

class TA : public Student, public Teacher {
public:
    TA() { cout << "TA()" << endl; }
    ~TA() { cout << "~TA()" << endl; }
};

int main() {
    TA ta;
    return 0;
}
```

### เฉลย

```
Person()      ← Virtual base class สร้างก่อน (สร้างครั้งเดียว!)
Student()     ← base class ตัวแรก (ตามลำดับใน class declaration)
Teacher()     ← base class ตัวที่สอง
TA()          ← ตัว TA สร้าง

~TA()
~Teacher()
~Student()
~Person()     ← Virtual base class ทำลายทีหลังสุด
```

**⚠️ สำคัญ:** ด้วย virtual inheritance, `Person()` ถูกเรียก **ครั้งเดียว** (ไม่ใช่ 2 ครั้ง)

## 📘 Final 75

### โจทย์แนว: Composition ใน Inheritance + Constructor Parameters

```cpp
#include <iostream>
using namespace std;

class Engine {
    int hp;
public:
    Engine() : hp(0) { cout << "Engine()" << endl; }
    Engine(int h) : hp(h) { cout << "Engine(" << h << ")" << endl; }
    ~Engine() { cout << "~Engine()" << endl; }
};

class Vehicle {
    Engine e;
public:
    Vehicle() { cout << "Vehicle()" << endl; }
    Vehicle(int hp) : e(hp) { cout << "Vehicle(" << hp << ")" << endl; }
    ~Vehicle() { cout << "~Vehicle()" << endl; }
};

class Car : public Vehicle {
    Engine turbo;
public:
    Car() { cout << "Car()" << endl; }
    Car(int hp, int tHp) : Vehicle(hp), turbo(tHp) { cout << "Car(" << hp << "," << tHp << ")" << endl; }
    ~Car() { cout << "~Car()" << endl; }
};

int main() {
    Car c(200, 50);
    return 0;
}
```

### เฉลย

```
Engine(200)           ← Vehicle::e สร้าง (เป็น member ของ base class)
Vehicle(200)          ← Base class Vehicle สร้าง
Engine(50)            ← Car::turbo สร้าง (member ของ Car)
Car(200,50)           ← ตัว Car สร้าง

~Car()                ← Car ทำลาย
~Engine()             ← Car::turbo ทำลาย
~Vehicle()            ← Base Vehicle ทำลาย
~Engine()             ← Vehicle::e ทำลาย
```

## 📘 Final 76

### โจทย์แนว: Copy Constructor Tracing

```cpp
#include <iostream>
using namespace std;

class Box {
    int val;
public:
    Box(int v) : val(v) { cout << "Box(" << v << ")" << endl; }
    Box(const Box& b) : val(b.val) { cout << "Box(copy:" << val << ")" << endl; }
    ~Box() { cout << "~Box(" << val << ")" << endl; }
};

int main() {
    Box b1(10);
    Box b2(b1);       // Copy constructor
    Box b3 = b1;      // Copy constructor (ไม่ใช่ assignment!)
    Box b4(20);
    b4 = b1;          // Assignment operator (default)
    return 0;
}
```

### เฉลย

```
Box(10)           ← b1 สร้าง
Box(copy:10)      ← b2 สร้างจาก copy constructor
Box(copy:10)      ← b3 สร้างจาก copy constructor (Box b3 = b1 คือ copy ไม่ใช่ assign!)
Box(20)           ← b4 สร้าง
                  ← b4 = b1 ใช้ default assignment (ไม่มี output)

~Box(10)          ← b4 ทำลาย (ค่า = 10 เพราะถูก assign จาก b1)
~Box(10)          ← b3 ทำลาย
~Box(10)          ← b2 ทำลาย
~Box(10)          ← b1 ทำลาย
```

**⚠️ จุดหลอก:** `Box b3 = b1;` ดูเหมือน assignment แต่จริงๆ คือ **copy constructor** เพราะเป็นการสร้าง object ใหม่!

## 📘 Final 77

### โจทย์แนว: Mixed Composition + Virtual Inheritance + Constructor Order

```cpp
#include <iostream>
using namespace std;

class Date {
public:
    Date() { cout << "Date()" << endl; }
    ~Date() { cout << "~Date()" << endl; }
};

class Person {
    Date d;
public:
    Person() { cout << "Person()" << endl; }
    ~Person() { cout << "~Person()" << endl; }
};

class Student : virtual public Person {
public:
    Student() { cout << "Student()" << endl; }
    ~Student() { cout << "~Student()" << endl; }
};

class Teacher : virtual public Person {
    Date hireDate;
public:
    Teacher() { cout << "Teacher()" << endl; }
    ~Teacher() { cout << "~Teacher()" << endl; }
};

class TA : public Student, public Teacher {
public:
    TA() { cout << "TA()" << endl; }
    ~TA() { cout << "~TA()" << endl; }
};

int main() {
    TA ta;
    return 0;
}
```

### เฉลย

```
Date()         ← Person::d สร้าง (member ของ virtual base)
Person()       ← Virtual base Person สร้าง
Student()      ← base Student สร้าง (ไม่สร้าง Person ซ้ำ เพราะ virtual)
Date()         ← Teacher::hireDate สร้าง (member ของ Teacher)
Teacher()      ← base Teacher สร้าง (ไม่สร้าง Person ซ้ำ เพราะ virtual)
TA()           ← ตัว TA สร้าง

~TA()
~Teacher()
~Date()        ← Teacher::hireDate ทำลาย
~Student()
~Person()
~Date()        ← Person::d ทำลาย
```

## 🎯 เทคนิคการ Trace ลำดับ Constructor/Destructor

### ขั้นตอนที่ 1: วาด Hierarchy
```
วาดแผนภาพ class ทั้งหมด ดูว่า:
- ใครสืบทอดจากใคร
- ใครมี member objects อะไร
- มี virtual inheritance หรือไม่
```

### ขั้นตอนที่ 2: เขียนลำดับสร้าง
```
1. Virtual Base Class (ถ้ามี) + member ของ virtual base
2. Non-Virtual Base Class (ซ้ายไปขวา) + member ของแต่ละ base
3. Member objects ของ class ปัจจุบัน (ตามลำดับประกาศ)
4. Body ของ constructor ปัจจุบัน
```

### ขั้นตอนที่ 3: เขียนลำดับทำลาย
```
ย้อนกลับทุกอย่างจากขั้นตอนที่ 2!
```
