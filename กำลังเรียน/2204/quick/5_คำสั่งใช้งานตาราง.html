บทที่ 5  คำสั่งใช้งานตาราง

โครงสร้าง <table> · แท็กย่อย · colspan/rowspan · table + CSS · โจทย์พร้อมเฉลย · accessibility

ใช้ตารางเมื่อไหร่: เฉพาะ "ข้อมูลที่เป็นตารางจริง ๆ" (แถว–คอลัมน์สัมพันธ์กัน เช่น ตารางเรียน งบการเงิน) · ห้ามใช้ตารางจัด layout หน้าเว็บ — งานนั้นใช้ CSS Flexbox / Grid

5.1 โครงสร้างพื้นฐานของ <table>

<table> → <tr> (แถว) → <th> (หัวตาราง) / <td> (ช่องข้อมูล)

border="1" เป็นวิธีเก่าไว้ดูโครงชั่วคราว ของจริงจัดเส้นด้วย CSS (หัวข้อ 5.6)

5.2 แท็กย่อยภายใน <table>

<caption> · <thead> · <tbody> · <tfoot>

caption = ชื่อตาราง · แบ่งส่วนหัว/เนื้อ/ท้าย ช่วยให้อ่านง่าย พิมพ์แล้วหัวตารางซ้ำทุกหน้า และ screen reader เข้าใจโครง

<colgroup> · <col> — กำหนดสไตล์ทั้งคอลัมน์รวดเดียว

5.3 คุณสมบัติจัดรูปแบบเพิ่มเติม — <th>/<td> ที่กินหลายช่อง

colspan (รวมแนวนอน) · rowspan (รวมแนวตั้ง)

แอตทริบิวต์เก่าที่เลิกใช้ใน HTML5 (ย้ายไปทำใน CSS ทั้งหมด): cellpadding → padding · cellspacing / border → border-collapse + border · align / bgcolor / width → property ของ CSS

5.4 <table> พร้อมการใช้ CSS (แบบใช้งานจริง)

border-collapse + zebra stripe + hover

border-collapse:collapse รวมเส้นคู่เป็นเส้นเดียว · tr:nth-child(even) ทำแถบสลับสี · ครอบด้วย <div style="overflow-x:auto"> เพื่อให้เลื่อนได้บนจอมือถือ

5.5 โจทย์ที่ใช้งาน <table> พร้อมเฉลย

โจทย์: สร้างตาราง "ผลการเรียน" ให้มี
  1. <caption> ชื่อว่า ผลการเรียน ภาค 1/2568
  2. หัวตาราง 3 คอลัมน์: รหัสวิชา / หน่วยกิต / เกรด
  3. ข้อมูล 3 วิชา
  4. แถวสรุปใน <tfoot> แสดง GPA โดยช่องค่ารวมใช้ colspan="2"

เฉลย

5.6 การขยายความ — Accessibility ของตาราง

<th scope> + <caption> ทำให้ screen reader อ่านตารางรู้เรื่อง

scope="col" = th นี้เป็นหัวของคอลัมน์ · scope="row" = เป็นหัวของแถว เวลาอ่านช่องข้อมูล โปรแกรมจะพ่วงชื่อหัวที่เกี่ยวข้องให้อัตโนมัติ

เช็กลิสต์ตารางที่ดี: มี <caption> บอกว่าตารางเกี่ยวกับอะไร · หัวตารางใช้ <th> + scope ไม่ใช่ <td> ตัวหนา · จัดเส้น/ระยะห่างด้วย CSS · ครอบ overflow-x:auto สำหรับจอแคบ · ไม่ใช้ตารางจัด layout
