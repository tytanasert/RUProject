บทที่ 2  คำสั่งพื้นฐาน

พื้นฐาน HTML · ชนิดของแท็ก · ย่อหน้า · รูปภาพ · เส้นคั่น · หัวข้อ/รายการ · กำหนดรูปแบบ

ทุกตัวอย่างในหน้านี้แสดง ผลลัพธ์จริง คู่กับ โค้ด จากซอร์สชุดเดียวกัน ลองก๊อปโค้ดไปวางในไฟล์ .html ของตัวเองแล้วแก้เล่นได้เลย

2.1 พื้นฐานความรู้เอชทีเอ็มแอล — โครงกระดูกของเอกสาร

โครงสร้างขั้นต่ำของ 1 ไฟล์เว็บ

ทุกหน้าเว็บเริ่มด้วย <!DOCTYPE html> แล้วห่อด้วย <html> ข้างในแบ่ง 2 ส่วน: <head> = ข้อมูลของหน้า (ไม่แสดงผล) และ <body> = เนื้อหาที่ผู้ใช้เห็น 

<!DOCTYPE html>
<html lang="th">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>ชื่อที่แสดงบนแท็บเบราว์เซอร์</title>
</head>
<body>
  <!-- เนื้อหาที่ผู้ใช้เห็นอยู่ในนี้ -->
  <h1>หัวข้อหลัก</h1>
  <p>ย่อหน้าเนื้อหา</p>
</body>
</html>
ทำไมต้องมี <!DOCTYPE html>: บอกเบราว์เซอร์ให้ใช้โหมดมาตรฐาน (standards mode) ถ้าไม่ใส่ เบราว์เซอร์จะเดา ๆ (quirks mode) แล้วหน้าเพี้ยน · charset="UTF-8" จำเป็นมากสำหรับภาษาไทย ไม่ใส่แล้วอาจได้ตัวยึกยือ

2.2 ชนิดของ HTML Tag

Block-level vs Inline

Block (เช่น div, p, h1) กินความกว้างเต็มบรรทัด ก้อนถัดไปจึงขึ้นบรรทัดใหม่เสมอ · Inline (เช่น span, a, strong) ไหลต่อกันในบรรทัดเดียวจนกว่าจะเต็ม

แท็กปกติ (มีปิด) vs แท็กว่าง / void (ไม่มีปิด)

แท็กปกติมาเป็นคู่ <p>...</p> · แท็กว่างไม่มีเนื้อหาข้างใน จึงไม่มีตัวปิด เช่น <br> <hr> <img> <meta>

2.3 คำสั่งย่อหน้า

<p> · <br> · การยุบช่องว่าง · <pre>

HTML ยุบช่องว่าง/บรรทัดใหม่ที่พิมพ์ติดกันให้เหลือช่องเดียวเสมอ อยากได้ช่องว่างจริงใช้ &nbsp; · อยากคงรูปแบบที่พิมพ์ทุกตัวใช้ <pre>

2.4 แท็กจัดการรูปภาพ

ตัวอย่างรูปดึงจากอินเทอร์เน็ต (picsum.photos) ต้องต่อเน็ตจึงเห็นรูป — รูปที่ 2 จงใจใส่ path ผิดเพื่อโชว์ alt

<img> กับแอตทริบิวต์ src, alt, width, height

src = ที่อยู่ไฟล์รูป · alt = ข้อความแทนรูป (ใช้ตอนรูปไม่ขึ้น + ให้ screen reader อ่าน — ต้องมีเสมอ) · width/height = จองพื้นที่ กันหน้ากระตุกตอนรูปโหลด

ชนิดของ path: img/logo.png = relative (อ้างจากตำแหน่งไฟล์ html ปัจจุบัน) · /img/logo.png = root-relative (อ้างจากรากเว็บไซต์) · https://.../logo.png = absolute (URL เต็ม)

2.5 การสร้างเส้นคั่นในหน้าเว็บ

<hr> — เส้นแบ่งเนื้อหา (thematic break)

<hr> สื่อความหมายว่า "เปลี่ยนหัวข้อ/ประเด็น" ไม่ใช่แค่เส้นตกแต่ง หน้าตาของเส้นปรับด้วย CSS

2.6 การสร้างหัวข้อและรายการ

หัวข้อ <h1>–<h6>

เลข 1–6 คือ ระดับความสำคัญ/โครงสร้าง ไม่ใช่ขนาดตัวอักษร · 1 หน้าควรมี <h1> เดียว และห้ามข้ามลำดับ (h2 ไป h4 เลยไม่ควร)

รายการไม่มีลำดับ <ul> และมีลำดับ <ol> (ซ้อนกันได้)

รายการนิยาม <dl> / <dt> / <dd>

ใช้กับคู่ "คำศัพท์ → คำอธิบาย" เช่น อภิธานศัพท์ ตาราง metadata

2.7 กำหนดรูปแบบ (formatting เบื้องต้น)

แท็กตกแต่งคำ + แอตทริบิวต์ style

เลือกแท็กตาม ความหมาย ก่อน: <strong> = สำคัญ, <em> = เน้นเสียง ส่วน <b> <i> คือหนา/เอียงเฉย ๆ ไม่มีน้ำหนักความหมาย (รายละเอียดเต็มอยู่บทที่ 4)

สรุปแนวคิดของบท: HTML = "เนื้อหาคืออะไร" ไม่ใช่ "หน้าตาเป็นยังไง" (หน้าตาเป็นงานของ CSS) แนวคิดนี้ต่อยอดเป็น บทที่ 3 คำสั่งเชิงความหมาย
