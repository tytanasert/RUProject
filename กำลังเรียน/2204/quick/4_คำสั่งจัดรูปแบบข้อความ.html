บทที่ 4  คำสั่งจัดรูปแบบข้อความ

โครงสร้างข้อความ · แท็กตกแต่งคำ/วลี · Semantic text tags ใน HTML5

หลักคิดของบทนี้: HTML5 เลือกแท็ก "ตามความหมาย" ไม่ใช่ตามหน้าตา — หน้าตา (สี ขนาด ฟอนต์) เป็นงานของ CSS · แบ่งได้ 2 กลุ่ม: (1) จัดโครงสร้างข้อความ — heading, paragraph, quote, pre (2) ตกแต่งคำ/วลี — strong, em, code, abbr ...

4.1 แท็กจัดโครงสร้างข้อความ

heading · paragraph · br · hr

โครงกระดูกของเนื้อความ (รายละเอียด heading/list อยู่บทที่ 2)

<pre> + <code> — บล็อกโค้ด

pre รักษาช่องว่าง/บรรทัด · code สื่อว่า "นี่คือโค้ด"

<blockquote> · <q> · <cite> — การอ้างคำพูด

blockquote = อ้างยาวเป็นบล็อก · q = อ้างสั้นในบรรทัด (เบราว์เซอร์ใส่ " ให้เอง) · cite = ชื่อผลงาน/แหล่งที่มา

4.2 แท็กเน้นความหมาย: importance & emphasis

<strong> = สำคัญ · <em> = เน้นเสียง (ซ้อนกันได้)

4.3 การใช้งานแท็กตกแต่งต่าง ๆ

<b> <i> <u> <s> — ยังมีใน HTML5 แต่ความหมายแคบลง

ใช้เมื่อ "อยากให้ดูต่าง" โดยไม่ได้สื่อว่าสำคัญ/เน้นเสียง

<del> · <ins> — ติดตามการแก้ไขเอกสาร

<small> · <sub> · <sup> · <mark>

<abbr> · <dfn> · <code> · <kbd> · <samp> · <var>

กลุ่มแท็กสำหรับเนื้อหาเชิงเทคนิค — เอา title ใส่ abbr เพื่อให้ hover เห็นคำเต็ม

<bdo> — บังคับทิศทางการอ่านข้อความ

4.4 แท็กข้อความแบบมีโครงสร้างความหมาย (Semantic Tags)

หน้าตาเหมือนกัน แต่ความหมายต่างกัน

screen reader กับ Google เห็นสองบรรทัดนี้ไม่เท่ากัน

เลือกแท็กให้ถูก — เทียบแท็ก "หน้าตา" กับ "ความหมาย":
อยากได้ผลแท็กเชิงหน้าตาแท็กเชิงความหมาย (แนะนำ)
ตัวหนา<b><strong> (ถ้าสำคัญจริง)
ตัวเอียง<i><em> (ถ้าเน้นเสียง)
ขีดทับ<s><del> (ถ้าเป็นการลบ/แก้)
ตัวเล็ก/สี/ฟอนต์<font> (เลิกใช้แล้ว)ใช้ CSS
