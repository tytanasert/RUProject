COS2204 — quick reference

ตัวอย่าง HTML tag บทที่ 2–5 (อ้างอิงสารบัญหนังสือประกอบวิชา Client-Side Web Development)

ทุกหน้าแสดง ผลลัพธ์ที่ render จริง คู่กับ โค้ด HTML ของตัวอย่างเดียวกัน เปิดไฟล์ด้วยเบราว์เซอร์ได้เลย (ดับเบิลคลิก) — ไม่ต้องลงอะไรเพิ่ม
  • บทที่ 2 — คำสั่งพื้นฐาน

    โครงกระดูก HTML · block/inline/void tag · <p> <br> <pre> · <img> · <hr> · heading & list (ul/ol/dl) · แอตทริบิวต์ style

  • บทที่ 3 — คำสั่งเชิงความหมาย (Semantic)

    section article header footer nav aside · figure/figcaption · main mark time + โครงหน้าเว็บสมบูรณ์ที่รวมทุกแท็ก

  • บทที่ 4 — คำสั่งจัดรูปแบบข้อความ

    โครงสร้างข้อความ (blockquote q cite pre code) · strong em b i u s del ins · abbr dfn kbd samp var sub sup bdo · หน้าตา vs ความหมาย

  • บทที่ 5 — คำสั่งใช้งานตาราง

    table tr th td · caption thead tbody tfoot colgroup col · colspan/rowspan · table + CSS · โจทย์พร้อมเฉลย · scope & accessibility
